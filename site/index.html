PUBLIC LAUNCH STATUS

Website is public.
App access is not open.

This site introduces the Pinglet project. It does not create accounts, send messages or provide access to the live chat service.

Before public app access, the project still needs a signed Android release, real-device checks, final privacy and terms review, a monitored safety contact, and an operating team to review user reports.

Please do not use preview builds for real conversations or share private information while testing.
